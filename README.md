# ToDo List

Простий веб-додаток для керування списком завдань.

## Функціональність

- Додавання завдань
- Позначення завдань як виконаних
- Видалення завдань
- Фільтрація завдань
- Збереження даних

## Технології

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- REST API
- JSON

## Запуск

```bash
cd backend
npm install
npm start
```

Після запуску відкрити:

```text
http://localhost:3000
```

## Зберігання

Завдання зберігаються у файлі `backend/tasks.json`.

Проєкт виконано в рамках практичного завдання з використанням ChatGPT.
