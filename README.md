# ToDo List

Сучасний веб-додаток для створення та керування списком завдань.

## Функціональність

- ➕ Додавання завдань
- ✏️ Редагування завдань
- ✅ Позначення завдань як виконаних
- 🗑️ Видалення завдань
- 🔍 Пошук завдань
- 🔴🟡🟢 Встановлення пріоритету
- 📅 Встановлення дедлайну
- 📊 Статистика та прогрес виконання
- 🌙 Темна тема
- 🔎 Фільтрація завдань

## Технології

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- REST API
- JSON
- LocalStorage

## Запуск

```bash
cd backend
npm install
npm start
```

Після запуску відкрити:

```text
http://localhost:3000
```

## Зберігання даних

Завдання зберігаються на сервері у файлі:

```text
backend/tasks.json
```

`localStorage` використовується як резервне локальне зберігання.

## API

| Метод | Endpoint | Опис |
|---|---|---|
| GET | `/api/tasks` | Отримати завдання |
| POST | `/api/tasks` | Додати завдання |
| PUT | `/api/tasks/:id` | Редагувати завдання |
| PATCH | `/api/tasks/:id` | Змінити статус |
| DELETE | `/api/tasks/:id` | Видалити завдання |
